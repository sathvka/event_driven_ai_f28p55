# Event-Driven AI on F28P55x

## Project Overview

Research and implementation of event-driven, neuromorphic-inspired AI
on the TI F28P55x NPU for industrial applications.

## Objective

To investigate sparse and event-driven AI approaches that can reduce
computational and energy requirements while maintaining AI accuracy,
latency, and real-time control performance.

## Current Stage

Project initiated.

### Currently Learning
- Biological inspiration for event-driven computing
- ANN vs SNN
- Event-driven AI
- TI F28P55x architecture

## Project Roadmap

1. Biological and neuromorphic concepts
2. F28P55x architecture
3. Data acquisition
4. Event encoding
5. AI model development
6. Model quantization and NPU mapping
7. Event-triggered runtime
8. CLA–NPU integration
9. Performance evaluation
